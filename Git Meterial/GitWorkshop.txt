Git Flow : 

Overview: Git Flow uses a main branch for production, a develop branch for integration, and feature branches for new work. Hotfix and release branches handle specific needs.

Branches and Their Purpose:

   1. main branch:

        - Represents production-ready code.
        - Only stable, release-ready commits should be present here.

   2. develop branch:

        - Used as the integration branch for features and fixes.
        - It contains the latest development changes that are not yet released.

   3. Feature branches:

        - Created from develop.
        - Used for developing new features.
        - Once complete, they are merged or rebased back into develop.
        -  Usually short-lived.

    4. Release branches:

       - Created from develop when it's time to prepare a new production release.
       - Used for final testing, bug fixes, and versioning.
       - Merged into both main and develop upon release.

   5. Hotfix branches:

       - Created from main to address urgent issues in production.
       - After the fix, the branch is merged into both main and develop.

Note:
Instead of merging, developers may rebase their feature branches onto the target branch (e.g., main or develop) to maintain a linear commit history. This can help keep the project history clean, though it should be done with caution on shared branches.
